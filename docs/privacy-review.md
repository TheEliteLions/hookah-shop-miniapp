# Privacy review checklist — заполнить до production регистрации

Публичная регистрация отключена по умолчанию, пока владелец не проверит уведомление и обязательные настройки. Supabase Auth обрабатывает e-mail; поэтому сервис не является сайтом «без персональных данных».

- [ ] Указать реальное юридическое лицо/контролёра и рабочие контакты, предоставленные владельцем.
- [ ] Проверить применимое основание обработки, цели, срок хранения, права субъектов и получателей данных с юристом.
- [ ] Проверить DPA, регион хранения, subprocessors, резервное копирование и удаление в настройках фактического Supabase проекта.
- [ ] Подготовить и опубликовать проверенное уведомление о конфиденциальности и ссылку рядом с регистрацией.
- [ ] Проверить e-mail confirmation, reset URL и allowlist redirect origins.
- [ ] Установить `VITE_PUBLIC_SIGNUP_ENABLED=true` только после review; иначе оставлять `false`.
- [ ] Не собирать checkout address/phone/payment. Сейчас такие поля отсутствуют.

Не добавляйте вымышленные реквизиты, контролёра или правовое основание.
